Keeping Barline Going

Barline is free and open source. The Microsoft Store is the easiest way to install it and keep it updated automatically. A one-time Barline Plus purchase unlocks additional customization and helps fund continued development.

The complete source code is on GitHub for anyone who wants to build, modify, study, or contribute to Barline.

Buying it is never required, but it is a great support for the development of the project. Thank you for your support!

Before You Start

Barline needs Windows 11, and it sits where the Widgets button does. Turn that off first, under Settings, then Personalization, then Taskbar, then Taskbar items.

Once it is running, right-click the widget for its settings. The same menu is on the icon in the notification area.
